# v1.1.2 板上按键操作指南

操作入口：SW4 功能键、SW1 复位键、SW3 电源开关、HT1621B 段码 LCD。全部用户操作在板上完成。

## 按键规则

| 页面 | 短按一次 | 双击 | 按住 1.5～不足 3 秒松开 | 按住至少 3 秒松开 |
|---|---|---|---|---|
| 称重页 | 稳定去皮 | 切换 g/kg 并保存 | 空秤归零、清除皮重 | 进入设置菜单 |
| 菜单列表 | 下一项，末项后循环 | 返回称重页 | 进入当前项 | 留在菜单列表 |
| 选项页 | 切换选项 | 取消，返回菜单 | 保存当前选项 | 取消，返回菜单 |
| 数字编辑 | 当前闪烁位加一，9 后回 0 | 切到下一位，从个位向左 | 确认数值 | 取消本次编辑/标定，返回菜单 |
| 标定空秤/加载页 | 保持当前步骤 | 取消标定，返回菜单 | 稳定后采集 | 取消标定，返回菜单 |
| 清除标定确认页 | 保持确认页 | 取消 | 执行清除 | 取消，返回菜单 |
| 原始计数/信息/自检页 | 下一页 | 返回菜单 | 返回菜单 | 返回菜单 |
| 待机 | 唤醒 | 第一次按下唤醒 | 第一次按下唤醒 | 第一次按下唤醒 |

短按动作在释放后等待 300ms 再执行；第二次按下落在该窗口内即识别为双击。30ms 消抖过滤触点抖动。长按动作在释放时执行，因此按住三秒进菜单不会先触发一次归零。

SW1 只负责复位：重新启动、清除运行时皮重和零点跟踪、恢复保存的参数。SW3 负责实际断电；软件待机保留主控时基与按键轮询。

## 显示怎样读

屏幕的四个小数字位置用于状态或菜单编号，其余六个数字按逻辑第 5～10 位排列显示数值；玻璃可能把这六位分成两组三位。字母用七段形状近似显示，例如 `b`、`d`、`r`、`n` 为小写形。

称重时标题中 `g` / `kg` 表示单位，`t` 表示已设置皮重，`S` 表示稳定。g 显示一位小数，例如 `500.0`；kg 显示四位小数，例如 `0.5000`。分度仍按质量区间选择：低段 0.1g，中段 0.5g，高段 1g。

开机先全段点亮 2.5 秒，显示版本 1.1.2 至第 3.5 秒，然后进入称重页。反馈文字显示约 1.2 秒，之后恢复当前页面。

| 显示 | 含义与操作 |
|---|---|
| `no CAL` | 尚无有效标定，进入 CAL 完成标定 |
| `------` | 正在等新鲜采样，等待采样建立 |
| `S` | 样本窗口满足判稳条件，可确认去皮或标定 |
| `UnSt` | 本次测量不稳定，保持秤台不动后再次确认 |
| `no Ad` | 当前样本不足或已过期，等待有效采样 |
| `LoAd` | 当前有负载，空秤归零未执行；移除物品，或用短按去皮 |
| `rAnGE` | 毛重超过正常 5000g 范围，或编辑数值超出范围 |
| `OL` | 毛重达到 5250g；移走超载物 |
| `SEnSor` | HX711 连续 1 秒没有有效采样，或读到满码 |
| `SPAn` | 标定 ADC 跨度太小、方向或顺序不符合要求，检查砝码后重试 |
| `OrdEr` | 后一个标定质量没有大于前一点，重新编辑质量 |
| `dAtE` | 年月日组合无效，重新编辑日期 |
| `FLASH` | 参数写入未成功，原参数继续使用；重试保存 |
| `donE` / `SAvEd` | 操作完成 / 参数已经保存 |

## 全部菜单

从称重页长按至少 3 秒松开进入数字菜单；初始项为 `01`（清除皮重）。每次短按向下移动一项，长按 1.5～不足 3 秒松开进入。下表按实际循环顺序列出。

| 次序 | 显示编号（旧版名称） | 功能 | 编辑范围/选项 | 掉电保存 |
|---|---|---|---|---|
| 1 | **`01`**（UntArE） | 清除皮重，显示毛重，返回称重页 | 立即执行 | 皮重只存在本次运行 |
| 2 | **`02`**（UnIt） | 显示单位 | g / kg | 是 |
| 3 | **`03`**（bEEP） | 蜂鸣器模式 | OFF 静音、ACt 有源、PASS 无源约500Hz | 是 |
| 4 | **`04`**（OFF） | 空秤无操作待机时间，单位秒 | 0～86400；0 关闭自动待机；默认120 | 是 |
| 5 | **`05`**（StAb） | 最近8点峰峰差判稳阈值，单位ADC计数 | 1～1000000；默认64 | 是 |
| 6 | **`06`**（rAtE） | 屏幕刷新周期，单位ms | 100～200；默认200，即5Hz | 是 |
| 7 | **`07`**（CAL） | 1～3点标定向导 | 默认1点20g，可选2/3点、空秤、各砝码总质量 | 最后一点后整体保存 |
| 8 | **`08`**（rAW） | 查看HX711原始计数 | 低6位、高位两页 | 查看页 |
| 9 | **`09`**（InFo） | 查看设备信息 | 版本、编号、年份、月日、5000g容量、标定点数 | 查看页 |
| 10 | **`10`**（Id） | 设置设备编号 | 000000～999999，保存为SCALE-xxxxxx | 是 |
| 11 | **`11`**（dAtE） | 设置标定日期 | 年2000～9999、月1～12、日1～31，验证闰年与月份 | 是 |
| 12 | **`12`**（CLr） | 清除标定 | 进入SUrE确认页后再次长按执行 | 是 |
| 13 | **`13`**（tESt） | 屏幕自检 | 全段点亮、1234/123456与小数点、全空白、1304控制器RAM核对 | 查看页 |
| 14 | **`14`**（SLEEP） | 立即软件待机 | LCD关闭、HX711掉电、LED熄灭 | SW4唤醒 |
| 15 | **`15`**（End） | 返回称重页 | 立即返回 | — |

`StAb` 越小，稳定判定越严格；阈值满足后还要连续保持500ms。修改后重新积累采样窗口。`rAtE` 只改变画面刷新周期，HX711 的实际采样率由 RATE 硬件连接决定，本板设计10SPS。

蜂鸣器出厂默认 `OFF`。进入 `bEEP`，短按选择 `ACt` 或 `PASS`，长按确认；使用与实物器件一致的模式。成功操作一声，失败操作三声；量程/采集异常在称重页每两秒重复三声。静音设置停止已有提示音并保存。

## 怎样逐位输入数字

以把编号改为 `000123` 为例：

1. 进入编号 `10`（Id）；当前闪烁位是个位。
2. 短按把个位改成3。
3. 双击，十位闪烁；短按改成2。
4. 再双击，百位闪烁；短按改成1。
5. 长按1.5～不足3秒松开，出现SAvEd，保存为 `SCALE-000123`。

某位是9时，再短按回0，不向高位进位。双击依次选个位、十位、百位……然后回个位。七位的判稳阈值在选中百万位时向左移动六位显示窗口。输入超范围会显示rAnGE并留在编辑页；长按3秒取消。

设置日期时依次确认年、月、日，最后确认有效日期后才保存。退出中间步骤会保留原日期。

## 用20g砝码完成第一次标定

v1.1.2默认选择1点，默认质量20g。确认动作均为按住约2秒后松开；按到3秒会取消当前标定并返回菜单。

1. 进入菜单编号07（CAL），点数显示1，长按确认。
2. 显示ZERO，清空秤盘，等上方出现S，长按记录空秤。
3. 进入砝码质量编辑，默认20。质量输入不显示无用前导零，数值在右侧；直接长按确认。
4. 显示C1g与20，放上20g砝码，等S，长按采集。
5. 出现保存提示并返回称重页；移走砝码，读数应回到约0.0；再放回20g，检查约20.0。

20g是标定点质量，传感器量程设置仍为5000g。程序检查ADC跨度至少64计数，传感器正/负输出方向均支持。

## 两点、三点与修改砝码质量

点数选择页短按按1→2→3→1循环。两点默认500g/2500g，三点默认500g/2500g/5000g，各点质量都能逐位改为手头砝码的递增总质量。

确认空载后依次“编辑并确认质量→放上对应总质量→等S→长按采集”。最后一点才写入Flash；中途双击或长按3秒取消，保留原标定。数值窗口里的闪烁位可短按修改，双击向高位移动；前导零只在当前被选中时显示，便于看清实际质量。

## 日常称重、去皮与归零

放上物品后观察数值；S表示稳定。需要容器时先放空容器，等S后短按一次，净重变为零并显示t；再加入物品读取净重。再次短按会用当前总负载替换上次皮重。移走容器可以显示负净重。

清除皮重：进入菜单第一项01（清除皮重），长按确认。空秤归零：移去所有物品，稳定后长按1.5～不足3秒松开。已有标定时归零只接受原空秤基线附近±0.1g，0.5g真实物品不会被归零吞掉。

去皮只改变净重，秤盘上容器与物品总重仍受5kg限制。超过5kg出现rAnGE，达到5.25kg出现OL。小分度代表显示步进，实物误差按砝码测试确定。

## 查看原始计数、设备信息与自检

rAW短按在rA-L/rAWL低六位和rAWH高位间切换。绝对计数为“高位绝对值×1000000+低六位”，负号由低位标题rA-L及高位负数标识。

InFo短按依次查看版本、编号数字、年份、月日MMDD、容量5000、标定点数。设备无日期时年与月日为0。

编号13自检页短按依次显示所有段、1234与123456及小数点、空白、RAM核对结果。第四页上方显示1304，数值0表示上一幅测试图与HT1621内部RAM一致，1表示不一致，2表示尚未读取。这个结果核对数字通信，玻璃实际亮段通过前三页观察。全段模式直接写满HT1621的32个RAM单元，与数字字模无关。固定缺段的定位见[段码映射说明](lcd-mapping.md)。

## 待机、复位与参数

默认120秒自动待机只在已标定、无皮重、稳定空秤、原始计数和滤波换算值均在±0.1g内时计时。菜单操作和按住按键会重置空闲时间。真实小负载、晃动、超载和采集异常不会进入自动待机。

待机后按一下SW4，重新启动HX711并建立新样本；这次按键不会误执行去皮。运行时皮重和零点保留，真正断电或SW1复位后恢复保存的标定基线。

掉电保存项为：标定曲线、单位、蜂鸣器、待机时间、判稳阈值、刷新周期、设备编号和日期。皮重与慢速零点跟踪只留在RAM。两页参数轮换保存，并验证CRC32；升级v1.1.2时读取v1.0.2记录，新增刷新周期使用200ms。

菜单编号显示在上方最后两位，其他数值位置在菜单列表时留空。进入后的参数页仍显示数值、单位或短提示；编号07是标定入口。
