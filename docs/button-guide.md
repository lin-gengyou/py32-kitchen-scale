# v2.0.1 完整按键操作指南

日常操作使用SW4功能键；SW1硬件复位，SW3实际电源开关。段码LCD显示重量与编号菜单。蓝牙是可选远端入口，板上操作独立完成全部设备功能。

## 先用20g完成一次称重

1. 外部电源上电，打开SW3。屏幕全段自检2.5秒，随后显示版本2.0.1，3.5秒后进入称重页。
2. 若有 `noCAL`：SW4按住至少3秒再松开，进入菜单01。
3. 短按6次到07，按住约2秒松开；默认点数1，再按住约2秒确认。
4. 显示ZERO，清空秤盘，等待上方S，按住约2秒记录空秤。
5. 质量编辑默认20g，直接按住约2秒确认。
6. 显示C1g与20，放上20g砝码，等S，按住约2秒采集并保存。
7. 返回称重页。移走砝码应接近0.0，再放20g应接近20.0。

确认键按1.5～不足3秒后松开，按到3秒属于取消/菜单。20g是标定点，传感器量程仍为5000g。后续取得大质量标准砝码后，用相应点核对高量程，或做多点标定。

## 怎样读屏

上方4位显示单位/状态/菜单号；数值区原有6个位置。本版默认跳过已知缺段的第三位，读数从其余5位顺序读取，中间保留一个空位。通过菜单19可切回6位。负号移入上方标题，5000.0g仍能完整显示。

- g显示一位小数，kg显示四位；分度仍按实际质量为0.1/0.5/1g。
- 上方S表示稳定；t表示有皮重；负净重在上方显示减号。负kg时该符号使用标题第三位。
- 开机及菜单13的全段自检点亮全部物理段，包括已知异常位。
- 字母采用七段近似字形；菜单用01～21，选择页用数字选项值。
- 信息提示保持约1.2秒后恢复当前页。

| 显示 | 含义/处理 |
|---|---|
| noCAL | 未标定，进入07 |
| 五/六条横线 | 正在等待新鲜采样 |
| UnSt | 未稳定，等S再确认 |
| no Ad | 有效样本不足，等待采样 |
| LoAd | 原零点附近存在负载，清空后归零；容器应使用短按去皮 |
| rAnGE | 毛重>5000g，或输入数值超范围 |
| OL | 毛重≥5250g，减载 |
| Err / SEnSr | HX711超时、满码或读取错误 |
| bAtt / 电压 | 所选电池模式低电；显示当前电压，单位V |
| bAtt / Err | 电池模式ADC错误，程序约每5秒重新初始化 |
| SPAn | 标定跨度不足64个计数、点顺序或方向不符合条件 |
| OrdEr | 新质量没有大于上一点 |
| dAtE | 日期组合无效 |
| FLASH | 本次保存失败，保留原有效配置，可重试 |
| donE / SAvEd | 操作完成 / 保存成功 |

## 逐位编辑数字

进入10设置编号，个位先闪烁：短按改成3，双击移到十位改成2，再双击移到百位改成1，长按约2秒保存为SCALE-000123。每位独立0～9循环，无自动进位。

5位显示模式下选择更高位会向左平移窗口，因此6位编号和7位判稳阈值仍可完整编辑。砝码质量的无用前导零隐藏，选中高位0时保留该0用于编辑。超范围显示rAnGE并保留编辑页。

日期依次输入年→月→日，最后校验后保存；中途退出保留原日期。

## 日常去皮、归零和称重

放物品读重量，S表示稳定。放空容器，等S后短按，净重为0并出现t；加入物品读净重。再次短按会用当前总负载替换皮重。移走容器显示负净重。菜单01只清除皮重。

手动归零要求已标定时毛重在原空秤基线±0.1g，稳定且新鲜；按约2秒松开，同时清皮重。放着0.5g不会被归零吞掉。启动时也只在已知空秤基线附近稳定归零。总负载超过5000g时，即使已经去皮，仍进入量程保护。

超过200.5g切0.5g分度、低于199.5g回0.1g；超过1001g切1g、低于999g回0.5g。滞回减少边界跳动；显示分度与实际测量误差分别评估。

## S稳定标志与菜单05

05=0为自动模式：用保存的标定比例换算0.2g峰峰值，当前20g/8973计数的标定约为90计数；未标定时采用128计数，便于完成首次标定。正数为手动峰峰计数门限。

进入S：完整8点窗口的最大值减最小值不超过门限，且连续保持500ms。已经进入S后，窗口峰峰值超过2倍门限，或8点均值相对进入时的锚点移动超过1个门限，立即退出S。这样小噪声不会反复清除S，缓慢增加物料也会离开旧稳定点。

重量仍按实时采样刷新，S常亮不锁住数字。0.2g是稳定识别的峰峰容差，实际称量误差按砝码测量。旧V1/V2/V3配置的默认64计数自动升级为0，其他手动值保留，标定无需重做。新V4配置中手动输入64会继续按64工作。

## 多点标定

07点数页短按切1/2/3，默认质量分别为单点20g、两点500/2500g、三点500/2500/5000g。每个质量可改为现有砝码的递增总质量。

完成空秤后，依次“编辑质量→放对应总质量→等S→长按采集”。各点递增、ADC跨度单调且每段≥64计数；正/负输出方向均支持。最后一点才写Flash。中途取消、未稳或保存失败保留原标定。标定期间BLE帧为CALIBRATING，远端去皮回复BUSY。

## 提示音与待机

03选择与实物蜂鸣器一致的1有源或2无源，长按保存；成功/有效按键1声，失败3声，称重页故障约每2秒3声。0静音立即停止提示音并保存。无源方波来自1ms中断，提示音持续期间继续采样。

默认只有已知空秤、无皮重、稳定且原始/滤波都在±0.1g附近，无操作120秒才自动待机。持续负载/小负载会保持运行；菜单页持续保持唤醒。待机关闭LCD/HX711/LED与ADC，保留MCU时基、SW4和BLE。第一次按SW4只唤醒，重建新样本后再操作。PING只维持无线心跳，WAKE明确唤醒。

## 外部供电、电压与电池配置

当前选17=0：外部供电。电池百分比为-1/未知，输入端没有接电池也不会报低电。16五页：1601输入端mV、1602主控VDDA mV、1603估算百分比、1604状态、1605电源类型。

状态值：0等待、1正常、2低电、3严重低电、4ADC错误。默认每125ms采一组PB1与内部参考，每8组更新平均电压；低电连续3次平均值才生效，恢复保留100mV滞回。电池模式低电/故障时显示警告，去皮与标定暂停。

| 17选项 | 类型 | 低电 / 严重低电 |
|---|---|---|
| 0 | 外部电源 | 显示电压，电池告警关闭 |
| 1 | 单节锂电 | <3.3V / <3.0V |
| 2 | 两节碱性 | <2.1V / <1.8V |
| 3 | 两节镍氢 | <2.1V / <1.9V |

百分比为电压曲线估算。PB1直接检测BAT-SW，电阻为串联滤波而非分压；电压必须处于ADC电气范围。18参考校准值用于修正VBAT与VDDA读数：新值=旧值×万用表实测值÷屏显值，按1000～1400mV范围输入；外部电源模式可用VDDA实测对比。

## 维护、自检和蓝牙

08分低/高位查看最新HX711计数。09依次查看版本2.0.1、ID高/低位、日期、5000g容量、标定点数。13四页：全段、1234/数值顺序与小数点、全空白、1304 RAM核对结果。1304结果0=一致、1=不一致、2=尚未读取；RAM一致只表示控制器存储与发送值一致，玻璃实际点亮形状由眼睛观察。

蓝牙客户端启动、连接、去皮、唤醒和完整协议见[蓝牙说明](protocol.md)。彩屏的重量页、20g向导、设置与故障设计见[彩屏方案](color-display.md)。
