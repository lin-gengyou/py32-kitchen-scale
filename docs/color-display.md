# 彩屏用途与接入方案 · v2.0.0

彩屏作为主界面，段码屏同步显示重量。两者共用SW4按键与WeightState，标定、皮重、单位和故障各有唯一状态。当前交付[交互预览](../web/tft-preview.html)，运行蓝牙客户端本地服务后打开 `/tft-preview.html` 即可体验。

## 四类页面

| 页面 | 显示与操作 |
|---|---|
| 称重 | 大号净重、g/kg、稳定/变化、皮重、外部供电、近期蓝牙活动；保留现有短按去皮/长按归零/3秒菜单 |
| 标定向导 | “清空秤盘→确认20g质量→放20g等待稳定→采集并保存”；逐步高亮，显示未稳定、跨度不足等具体原因 |
| 设置 | 用中文或完整英文替代七段缩写；对应同一组01～21菜单、逐位编辑、保存/取消 |
| 诊断与异常 | 原始ADC、VBAT/VDDA、版本/编号；超载、传感器、电源错误以大字显示并停止普通重量显示 |

预览按160×80横屏比例展示布局，屏上按键仍使用SW4；它是交互设计，实际屏幕型号尚未知。排线类似FPC096H031-V0的标记尚不足以确认控制器、分辨率、偏移、RGB顺序和反色设置。常见0.96英寸80×160产品使用ST7735S，可作为核对候选，不能据此认定实物型号。

## 原理图接口

| FPC1针 | 信号 | 主控关系 |
|---|---|---|
| 1 | LEDA背光正 | 3.3V经33Ω，现有电路未接可控PWM |
| 2 | GND | 公共地 |
| 3 | RESET | 硬件上拉/RC复位，未接主控GPIO |
| 4 | DC/RS | PF0，经TXB0104 |
| 5 | SDA | PA7，经TXB0104，与HT1621 DATA共享 |
| 6 | SCL | PA5，经TXB0104，与HT1621 WR共享 |
| 7 | VCC | 3.3V |
| 8 | CS | PA4，经TXB0104 |

HT1621 CS为PB2、RD为PF1。屏幕接线按触点面和真实针号对应。TFT控制器可使用软件复位命令初始化；具体命令/等待时间按确认后的手册填写。现有背光支路常供电，显示休眠与背光断电是两个独立动作；后者需要可控背光硬件。

## 3KB RAM与16KB程序空间下的实现

80×160的RGB565完整缓冲需要25600B，而MCU总RAM为3072B。采用64B小块缓冲、字形逐行解码、窗口直写、局部刷新。完整固件当前约15KB程序、2KB静态与预留堆栈，保留独立4KB标定区；彩屏驱动/字库加入前先核算剩余空间。

1. 数字、标点、单位与少量状态字使用裁剪字库；先做完整英文标签，中文字只纳入实际出现的少数字形。
2. SPI1的PA5/PA7使用AF0，8MHz主时钟下可从4MHz SPI开始。每次发送32个RGB565像素为64B，约128μs，分块间返回主循环处理采样和按键。
3. 界面比较旧WeightState，重量变化只重画数字；稳定、皮重、菜单高亮分别更新小矩形。主重量画面保持5～10Hz。
4. SPI事务前释放PB2与PA4片选，PF1保持高；切PA5/PA7为SPI复用，仅拉低PA4。事务结束拉高PA4，恢复GPIO输出，再允许HT1621事务。
5. 初始化和退出休眠的长等待使用状态机计时，期间继续喂狗、收BLE与处理按键。蜂鸣器音调已从主循环移入1ms中断。
6. TFT实现独立控制器配置，提供宽高、X/Y偏移、方向、RGB/BGR、反色与初始化表；确认实物参数后再选用对应配置。

实际接入步骤：确认商品/供应商参数→匹配控制器初始化→先做红绿蓝白黑与边框测试→核对方向、颜色和有效区域→接入相同WeightState/UI状态→实物检查共享总线、BLE、提示音、待机。当前发布固件保持TFT CS高，日常功能由段码LCD完成。

参考候选：[Waveshare 0.96inch LCD](https://www.waveshare.com/wiki/0.96inch_LCD_Module)、[LCDWiki 0.96inch IPS Module](https://www.lcdwiki.com/0.96inch_IPS_Module)。
