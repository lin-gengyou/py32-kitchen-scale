在 Chrome 或 Edge 打开此页，点击连接，选择名称以 BT_ 开头的秤。

连接设置与操作说明

先在秤上用20g砝码完成标定。放容器，等待“稳定”，点击去皮；移走容器会显示负净重。标定和所有设备设置也可直接用秤上的SW4完成。

外部供电的电池百分比显示为未知。断线后页面自动重连并重新订阅；连续3秒没有重量帧时清空旧读数。页面的单位转换只影响本页。

电脑使用 python -m http.server 8765 --directory web --bind 127.0.0.1，打开 http://localhost:8765。Android平板使用支持Web Bluetooth的Chrome及HTTPS地址；iPad可使用原生BLE客户端连接FFF0服务，协议见仓库文档。
